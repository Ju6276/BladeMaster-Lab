论文的 E = 0.4 MPa 低于这些测量（相当于过熟香蕉）。熟香蕉的"软"主要来自黏弹性松弛和低断裂强度，而不只是低弹性模量；本项目是共旋弹性 + von Mises 塑性，可选牛顿黏性（`dynamic_viscosity`）和 Maxwell 黏弹性分支（`maxwell_tau`、`maxwell_fraction`），默认都为 0。

Maxwell 分支只有一个时间常数，按需要模拟的保持时长从 Torres 2012 的熟果数据取：秒级（压住几秒）用 \(\tau\) = 2.5 s、`maxwell_fraction` = 0.2（快支 0.165 / 三项和 0.80）；几十秒用 \(\tau\) = 22 s、0.4（两支 0.33 / 0.80）。1 s 内的约 20% 没有时间常数可依。论文材料预设不启用（论文模型没有黏弹性，Fig. 9 对照保持论文设置）；`franka_run --maxwell-tau --maxwell-fraction` 和 `scripts/indentation.py` 的同名参数打开。

## E5 内聚验证参数

扫描基准 **700 J/m²** 来自 BladeMaster §IV-C 的香蕉切割能量尺度；**7/70/1400** 分别取其 **0.01/0.1/2 倍**，用于灵敏度检查。7/70 覆盖损伤释放活跃的工况，700 保留论文配置，1400 检查阈值加倍。静置、无切割压入和切割依次核对基础材料、接触和断裂的能量收支；`diff_energy_validate.py` 只在切割层扫描四档 G_c。

E5 内聚验证算例使用强度 **σ=50 kPa**、断裂能 **G_c=7/70/700/1400 J/m²**；初始弹性单元的刚度为 **K=5e8 Pa/m**。初始刚性单元由 σ 与 G_c 决定，完整断裂位移 `δ_f=2G_c/σ`。近端柔度 λ 和 ADMM 系数 ρ 是增量求解参数，分别满足 `λσ<δ_f`、`ρ>σ/δ_f`；同一物理状态下改变 ρ，收敛后的粒子结果保持一致。上述数值用于独立力学算例。

## 参考文献里的标定方法

- **DiSECt**（论文 [1]，Heiden 等 RSS 2021 / AuRo 2023）：用 Jamdagni & Jia 2019 的真机数据（激光扫描网格 + 刀与末端之间的力传感器）标定。以刀具力曲线误差为目标，用 Adam 直接优化，或用 SGLD / HMC 做贝叶斯后验，BayesSim 作对照；苹果、土豆的力曲线 MAE 为 0.253 / 0.379 N。商用求解器（LS-DYNA）的对照数据中，材料的密度、Lamé 参数、屈服应力和失效应变取自农业力学文献和 USDA FoodData Central。代码与数据集：[NVlabs/DiSECt](https://github.com/NVlabs/DiSECt)。
- **BladeMaster 本身**：只在 Fig. 9 用一次真机竖直切香蕉的关节力矩估计做定性 / 量级对比，没有给出标定流程。
- **TLMPM 文献**（论文 [6]、[20]、[21]）：用解析解和标准力学算例验证数值格式，不涉及食材标定。
