## DexLab 已有内容

[DexLab](https://github.com/huangkiki/Dexlab) 的切割部分是独立的 CPU TLMPM 实现：

| 任务 | 材料 | 网格 / 步长 | 说明 |
|---|---|---|---|
| 豆腐对半切 | 60×30×30 mm，E = 6 kPa，ν = 0.35，ρ = 1100 | 7.5 mm，1024 粒子，0.5 ms | 合成参数；\(G_c\) = 0.5 J/m²，ζ = 0.9，摩擦 0.3 / 0.2，FLIP 0.95，\(s_n\) = 0.1 |
| 香蕉三刀 | 120 mm 长、最大直径约 24 mm 的弯曲合成几何；E = 6 kPa，ν = 0.35 | 6 mm（另有 5 mm），0.25 ms | 纯弹性；刀 0.2 kg |
| 豆腐 / 香蕉切 + 侧推 | 同上；豆腐另加 η = 5 Pa·s 牛顿黏性 | 豆腐 5 mm / 0.125 ms | 刀在最后一刀切缝内侧推 |
| 交叉浅切 | 豆腐 | — | 旋转 90° 再浅切 |

本项目的 `geometry.py` 采样与模板、`run.py` 推切轨迹、独立刀路径的导向 PD 驱动、`replay_style.py` 场景样式来自 DexLab（Apache-2.0）；香蕉几何沿用其合成形状。`--material dexlab-baseline` 复现其 E = 6 kPa 的合成参数。

## 当前配置与单位

| 参数 | 当前用途 | 数值来源 |
|---|---|---|
| `young_modulus`、屈服应力 | 材料弹性和塑性，Pa | 论文预设或独立力学算例配置 |
| `cutting_energy` | 方向接触功阈值的能量尺度，J/m² | 香蕉 700，论文 §IV-C |
| `sharpness` | 锋利度，0–1 | 香蕉 0.9，论文 §IV-C |
| `contact_reference_dt` | 固定罚接触刚度的参考时间，s | 香蕉 25 μs，本地时间细化设置 |
| `flip_reference_dt` | 固定单位时间传递耗散的参考时间，s | 实验显式记录；0 表示固定每步混合 |
| 刀接触距离 | m；默认随粒子半径，独立扫描可固定 | 几何/网格设置，见 METHOD |
| `dynamic_viscosity` | 牛顿黏度，Pa·s | 默认 0 |
| `maxwell_tau`、`maxwell_fraction` | 可选松弛时间 s 与剪切分支比例 | 默认关闭；按所研究材料另定 |

Maxwell 正向扩展使用一个松弛时间和一个剪切分支比例。已有秒级保持算例取 `maxwell_tau=2.5`、`maxwell_fraction=0.2`，几十秒保持算例取 `22`、`0.4`；这些是单支近似的本地算例设置。运行入口为 `franka_run --maxwell-tau <秒> --maxwell-fraction <比例>` 或 `scripts.indentation`。当前可微分主线的功能覆盖见 DIFFERENTIABLE。

## 阈值扫描与内聚算例

自然切割扫描的基准 **700 J/m²** 来自 BladeMaster 香蕉参数；**7/70/1400** 为其 **0.01/0.1/2 倍**。7/70 用于激活释放，1400 检查阈值加倍。三层任务为静置、无切割压入、切割；`scripts.diff_energy_validate` 在切割层扫描四档数值。

| 内聚算例参数 | 数值 | 来源与单位 |
|---|---|---|
| σ | 50 kPa | 本地独立力学验证设置 |
| G_c | 7/70/700/1400 J/m² | 沿用扫描数值；内聚能量定义见 METHOD |
| K | 5e8 Pa/m | 双线性单元的本地算例刚度 |
| 完全断裂位移 | `δ_f=2G_c/σ` | 内聚单元公式，m |
| λ、ρ | 按局部凸性与求解条件设置 | 数值分裂参数；固定物理状态时比较收敛解与梯度 |

原模型和内聚模型的 G_c 作用方式、损伤历史及切口生成机制统一在 [METHOD](METHOD.md) 的差异表说明。参数扫描的结果和失败项见 [RESULTS](RESULTS.md)。
